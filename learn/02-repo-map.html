Who may import whom

ARCHITECTURE.md in src/ks/ defines the seams, and tests/skeleton/test_boundaries.py enforces them.

  • contracts imports no other ks module. Everything else imports it.
  • Direction: runtime → gateway → (ToolDispatcher protocol) ← world. Only runtime/run.py wires world into gateway.
  • world never imports runtime. Agent processes import world.agents but never the gateway-side world.tools.
  • verify never imports recorder. It re-checks from files, so it can't share a bug with the writer.
  • The planner and the gateway never see fault, culprit or fault_tick. RunConfig.tcb_view() strips them (rule A3), and a test scans the planner source for them.
Why TCB?"Trusted computing base" is the small set of code you must trust: gateway, recorder, signer, witness, verify. Everything else (agents, tools) is treated as potentially wrong or hostile.

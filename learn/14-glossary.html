Quiz

1. Why does the gateway, not the tool, build the read and write sets?

Because a tool's own report is testimony. The gateway takes the write set from what the store actually holds for that seq and checks every read against real versions. A tool that lies is refused (tool_error), and the refusal is recorded.

2. An agent was suspended, but it had pre-signed envelopes. Why don't they work?

Suspend bumps the agent's epoch to a strictly higher number. Pre-signed envelopes carry the old epoch, so step 8 denies them with stale_epoch. The signer also refuses new signatures for a non-current epoch.

3. Why are steps 7–9 checked again inside the transaction?

To close the check-to-use window. If a suspend commits after the first check but before the tool runs, the re-read inside BEGIN IMMEDIATE catches it and nothing executes.

4. What is the point of record seq 1?

It is the gateway-signed seed record whose write set is exactly the initial data. It gives every state version an evidence record, and the taint and recovery walks stop at seed versions.

5. Why keep the IBAN as its own object instead of a column in the supplier row?

So it can be restored on its own. Reverting the row would also revert unrelated honest edits, like triage's risk note.

6. How can the record be trusted if the gateway writes it?

Three layers: a hash chain, a gateway signature, and a separate witness process that signs checkpoints with its own key and never reads the record. Verify re-checks all of them offline, and an anchor kept outside the run directory detects truncation.

7. Why does the monitor never name an agent?

Naming is a separate step done by lookup in the record (who wrote the evidence version). That keeps attribution evidence-based and independent of detector logic or agent claims.

8. A payment was already dispatched with tainted data. What does recovery do?

It flags it (dispatched_tainted). Irreversible effects that left are compensated or reported, never claimed undone. If a re-run's simulated payload equals the dispatched one, the flag can be dropped.

9. Why score against an oracle run?

You need an independent definition of "correct". S* re-runs the same seed with the fault off, and R and C are computed from effect differences, never from the system's own taint graph.

10. Name two things that would break in a real asynchronous deployment.

Examples: the tick-based visibility rule (writes visible next tick), reads that bypass the gateway (invisible to taint), the SQLite store assumption, and uid isolation inside one container.

11. What does a flood of bad requests from one connection cause?

After 8 recorded denials in a tick (FLOOD_K), the connection (not the agent) is suspended by a gateway control record. Extra frames are dropped and counted.

12. Why must verify never import the recorder?

So it can't share a bug with the writer. It re-derives chain, signatures and witness checks from the files alone.

How it works

Project Kill Switch. One mediated path, one record, three queries.

Every mediated action takes one path. Bypass writes are caught by reconciliation.

Three queries on the same graph

3aIdentify

Which agents may have started the fault?

  • Invariant detector raises an alert on the supplier row.
  • Lookup on records gives root candidates, not a verdict.

3bContain

Stop the spread without stopping everyone.

  • Suspend the agent. Revoke only after a person confirms.
  • Lineage hold on any action or outbox item whose recorded read set touches taint.
  • Outbox items are held, not cancelled.

3cRecover

Fix only what is tainted.

  • Recovery plan shown as a dry-run diff, approved first.
  • Taint-scoped revert: restore a row only if it still holds crm’s version. Triage edited the supplier row, so it is flagged, not overwritten.
  • Re-run deterministic honest steps (billing, payments, comms) through the outbox with idempotency keys; nothing is sent twice.
  • Cancel (outbox item): a step of the approved plan. Compensate the class C invoice; report anything that already left.
  • No LLM agent at the finale. An LLM step would become a re-plan queued for approval.

4Audit

Anyone can run verify. Tamper-evident up to the last witnessed head.

  • chain
  • signatures
  • witness heads
  • seq gaps
  • reconciliation
Limits: irreversible effects are held, compensated or reported, never reversed. Tamper is detected, not prevented. Design plan; nothing here is measured yet.
